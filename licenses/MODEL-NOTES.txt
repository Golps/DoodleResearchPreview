This preview runs five distinct Apple MobileCLIP2 image encoders: S0, S2, B, S3 and S4. They are not the Apple Foundation Models framework. Original checkpoints: https://huggingface.co/apple (MobileCLIP2 model collection).

Modified representations: image encoder weights are stored as per-channel INT8 where supported. Most of them (matrix multiplications and 1x1 convolutions, rewritten as matrix multiplications) are packed into ONNX Runtime's 8-bit MatMulNBits format with the same INT8 values, scales and zero points, and are dequantized tile by tile during FP32 computation. Weights are stored in a separate external data file beside each graph. Exporter metadata containing workstation paths has been removed; executable graph/tensor digests were verified unchanged by that cleanup. The encoder architecture and frozen trained parameters are retained; quantization changes their numerical representation and can affect outputs. There is no claim of equivalence to Apple's published evaluation results. The browser vocabulary uses normalized representations generated from each matching text encoder, compressed for storage and matching.

The optional S0 sketch assist is a project-fitted regularized readout of frozen Apple S0 image features. It is derived from 2,760 adapted Google Quick, Draw! examples (CC BY 4.0). It is active in Rounds by default and can be disabled in Testing for a comparison without assistance. Other encoders use image/text matching. Similarity scores are not probabilities.
